# Scriptorium — Design Spec

A calm, warm reading room for long-form PDFs: paper-toned surfaces, one rubric accent, serif where you *read or write*, sans-serif where you *operate*.

Files: `src/styles/tokens.css` (all variables, 3 themes) · `src/styles/base.css` (reset + primitives). Components consume tokens only — **no raw hex values in component CSS.**

## 1. Principles

1. **The page is the hero.** Chrome recedes (flat, low-contrast borders); the white sheet carries the only strong shadow.
2. **Margins are for thinking.** Notes feel like paper slips tucked beside the text, never floating UI over it.
3. **Quiet until needed.** Actions appear on hover/focus; nothing animates unless it explains a change.
4. **One accent.** Rubric oxblood marks *what you can act on or where you are* (primary button, current section, bookmark ribbon, links). Note colors are content, not chrome.
5. **Never lose your place.** Jumps always leave a visible way back (return pill).
6. **Accessible by construction.** Every text pairing is AA in every theme; focus is always visible.

## 2. Setup

```ts
// main.tsx — fonts first, then tokens, then base
import "@fontsource-variable/inter";                          // family "Inter Variable"
import "@fontsource-variable/source-serif-4";                 // family "Source Serif 4 Variable"
import "@fontsource-variable/source-serif-4/wght-italic.css"; // italics for quotes
import "./styles/tokens.css";
import "./styles/base.css";
```

Install: `@fontsource-variable/inter`, `@fontsource-variable/source-serif-4`, `lucide-react`. Icons: 18px, `stroke-width` 1.75 (base.css also sets `.lucide { stroke-width: 1.75 }`); 16px inside `.btn--sm`/segmented items.

Theme: `document.documentElement.dataset.theme = "light" | "sepia" | "dark"`. Set it (and `.invert-pages` on `<html>`) in an inline script before first paint to avoid a flash. `.invert-pages` only takes effect under `data-theme="dark"`.

## 3. Palette

| Role | Light (paper) | Sepia | Dark (charcoal) |
| --- | --- | --- | --- |
| App bg / surface / raised / sunken | `#f4efe6` / `#faf7f1` / `#fffdf9` / `#ebe4d6` | `#e9dcc1` / `#f1e6cd` / `#f7eed9` / `#dfd0b1` | `#1d1c1a` / `#252321` / `#2e2c29` / `#171615` |
| Margin column | `#efe9dd` | `#e4d6b9` | `#262421` |
| Page sheet | `#fffdf8` | `#f8efd9` | `#e3ddd0` (dimmed); inverted `#242321` |
| Text / secondary / muted | `#2a2622` / `#575046` / `#6a6155` | `#33281b` / `#58472f` / `#665539` | `#ece6db` / `#bdb5a7` / `#a1998c` |
| Accent (+hover) | `#962d22` (`#7a2219`) | `#8a2a1c` (`#701f13`) | `#ee9884` (`#f7b3a2`) |

**Rationale.** Neutrals are warm (hue ≈ 35–40°), never grey-blue, so long reading sessions feel like paper rather than a dashboard. Sepia is a deeper parchment, not yellow. Dark is charcoal with a brown undertone; pages are *dimmed paper* by default (`multiply` blend over `--page-sheet-bg`) and optionally truly inverted (`filter: invert(.86) hue-rotate(180deg) sepia(.12)`, sheet `#242321`, slightly lighter than the app so the page edge stays legible). Accent is a rubric oxblood — in dark it lightens to a coral so it stays ≥ 4.5:1. Danger (`--color-danger`) is a brighter red and is always paired with a label/icon, so it is never confused with the accent. Focus ring is ink-blue (`--color-focus-ring`), deliberately a different hue from the accent.

**Note colors** (`data-note-color="amber|sage|sky|rose|lavender"` → `--note-bg/-border/-text/-dot`). Light/sepia: pale tint + deeper hue border + very dark hue text. Dark: deep tint + muted border + pale hue text. `-dot` is a single mid-tone per hue (L ≈ 0.17–0.20) with ≥ 3:1 against every sheet and margin background, so anchors read on any theme.

**Margin column.** It is the page's "desk": a quiet step off the app background in every theme. In dark this is deliberate, not incidental — the column is `#262421` against the app's `#1d1c1a` (a lift of one surface step), so the margin reads as a band beside the page and notes sit on a visibly distinct ground, while staying clearly darker than the note cards on it.

**Verified contrast** (worst case across all surfaces): text 9.4–14.8 · secondary ≥ 5.9 · muted ≥ 4.7 · accent ≥ 5.7 · on-accent ≥ 7.5 · danger ≥ 4.7 · note text on note bg ≥ 8.0 · return pill text ≥ 9.2 · focus ring ≥ 4.7 (3:1 required) · input border ≥ 3.1 (3:1 required). Rules: `--color-text-muted` is for static captions only (not on hover/pressed fills); interactive text uses `secondary`/`text`/`accent`.

## 4. Typography

| Token | Size | Family | Use |
| --- | --- | --- | --- |
| `--font-size-xs` | 12px | UI | kbd, chips, captions, quote text in notes (12.5px) |
| `--font-size-sm` | 13px | UI | toolbar, buttons, tabs, metadata |
| `--font-size-note` | **13.5px**/1.5 | **Serif** | margin notes (review notes use `base`, 15px/1.55) |
| `--font-size-base` | 15px/1.5 | UI | body, outline, inputs |
| `--font-size-md` | 16px | Serif | book-card titles (600), h4 |
| `--font-size-lg` / `xl` | 18 / 22px | Serif (h1–h2) | section headings, empty-state titles |
| `--font-size-2xl` / `3xl` | 28 / 36px | Serif | "Library" heading / display |

Weights 400/500/600. Headings: serif 600, `letter-spacing: -0.011em`, `text-wrap: balance`. Numerals that change (page, %, zoom) use `font-variant-numeric: tabular-nums`. Light-on-dark text looks heavier than dark-on-light, so dark eases the UI body weight (`--font-weight-regular` 380) and the serif note body (`--font-weight-note` 340, vs 400 elsewhere); both are variable-font values, so there is no extra download.

## 5. Layout & surfaces

Constants: `--toolbar-height` 48 · `--sidebar-width` 300 · `--margin-column-width` 280 · `--page-gap` 24 · `--margin-note-width` 256 · `--book-card-width` 176 · `--review-thumb-width` 160.

### 5.1 Library (home)
- Container max-width 1184px, centered, padding 38px 32px 48px. Top line: brand mark ("Scriptorium", serif 19, accent book icon) left; right: *Install app* (when installable), a ghost icon button **Library & storage** (`HardDrive`, tooltip "Library & storage", `aria-label="Library and storage"`, opens §5.6) and the quiet theme switcher; hairline below. Header row: eyebrow "YOUR READING ROOM" (xs, tracked caps, muted), `h1` "Library" (serif 28) left, **Open PDF** (`.btn--primary`, `FilePlus`) right.
- **Folder chip** (`.folder-chip`, only while a library folder is linked): a 30px pill under the header — `Textbooks · synced 2 minutes ago` (name truncates first, the detail never does) with a `FolderCheck` icon; **Adding books 3 / 12** with a spinner while syncing; `CircleAlert` "Couldn’t sync “Textbooks”" after a failure. These open Library & storage. When the browser wants permission again it becomes a quiet accent pill (`--color-accent-subtle`, `ShieldAlert`) **Reconnect “Textbooks”** that reconnects in place (that has to happen from a click). A visually hidden `role="status"` announces state changes without the progress counts.
- **Now reading** (if any book; region "Pick up where you left off"): a `.card.now-reading` — the cover (148px, tilted −2°, a few page edges peeking past the fore-edge, a soft accent glow behind) · eyebrow "NOW READING · Opened 2 hours ago" (xs tracked caps, accent) · serif title · "Chapter 2: Newton's Laws / *2.2 The Second Law*" · a progress bar split into chapters (the current one emphasised) · "Chapter 2 of 5 · Page 142 of 612 · 36%" (tabular) · `.btn--primary` "Continue reading". Chapters come from `LibraryDocument.contents` — the top two outline levels, saved locally when the book is opened (only when they change), so the library never loads a PDF; a book without them shows just the title and one plain bar. It follows the newest book that has been opened and isn't missing from its folder; books that were never opened (`lastOpenedAt` 0) are never offered, and a book whose page count isn't known yet reads "Page 142". No time estimates or reading statistics — progress is pages and chapters.
- Grid: `repeat(auto-fill, minmax(176px, 1fr))`, gap 32px 24px.
- `.book-card`: cover `aspect-ratio 3/4`, radius 3px, `--shadow-sheet`, 7%-wide dark spine gradient on the left edge. Title serif 16/1.3 600, 2-line clamp, 12px below the cover, with a two-line minimum height so progress rows align across a grid row. In dark, cover images are dimmed to 90% brightness so white pages don't glare. Meta row: 3px progress track (`--color-surface-sunken`, fill `--color-accent`, radius 2) + `%` (xs, secondary, tabular). Sub-line "Opened 2 hours ago" xs muted ("Not opened yet" for a book nobody has opened).
- **Folder books** (`source.kind === 'folder'`): a small `Folder` glyph (13px, muted) ends the sub-line, its `title` is the path inside the folder. If the PDF has left the folder the card gets `.is-missing` — the cover dims to 50% and greyscale, doesn't lift on hover, and the sub-line reads `FileX` **File missing from folder** (secondary text, danger-coloured icon). The card stays clickable (`aria-disabled`, name ends "file missing from folder") so that opening it explains instead of failing silently: toast "“Title” isn’t in your library folder right now. Put the file back to read it — your notes are safe."
- Hover/focus-within: cover lifts `translateY(-3px)` + `--shadow-lg` (200ms, ease-out); overflow menu `.btn--icon.btn--sm` (`MoreHorizontal`) fades in at cover top-right. The card is one link/button; the menu is a *sibling*, never nested. Every book's menu starts with **Reset progress…**, then Remove → confirm dialog. A folder book's menu ends with a note instead of Remove, "Remove the file from the folder to remove this book." — removing it here would be undone by the next scan.
- **Reset progress** (`.library-dialog`, "Reset", danger button; focus starts on Cancel): "Reset “Title”?" — the body is built from what the book holds: "This returns you to the start and deletes 12 notes, 4 highlights and 3 bookmarks. The book stays in your library. This can’t be undone." (zero counts left out; a book with nothing reads "This returns you to the start of the book. It has no notes, highlights or bookmarks."), plus "Other devices using this folder will see the reset too." while a folder is linked. Afterwards the card reads 0% and "Not opened yet", it leaves Now reading, and a toast says "Reset “Title”". The zoom level and the book itself stay.
- `.dropzone`: 2px dashed `--color-border-control`, radius 14, padding 32. `.is-dragover`: border `--color-accent`, bg `--color-accent-subtle` (140ms). First run: the dropzone *is* the empty state, centered; beside **Open PDF** sits a secondary `.btn` **Link a folder…** (`FolderOpen`) with the line "Works with OneDrive and Google Drive folders too." Both are hidden unless folders can be linked and none is yet (so absent where folder sync is unsupported).

### 5.2 Reader shell
- `.reader` = grid, rows `48px 1fr`. `.reader__toolbar`: bg `--color-surface`, bottom 1px `--color-border-subtle`, padding 0 12px, gap 4px, two groups (`--start` flexes, `--end` hugs the right), separated inside by short 20px `.divider--vertical` hairlines (centered, not full height).
  Start → end: **Library** (`LibraryBig`) · sidebar toggle (`PanelLeft`, `aria-pressed`) · divider · back/forward (`ArrowLeft`/`ArrowRight`, disabled when unavailable) · title (serif 15/600) + current section (13px muted, after a `·`; the section truncates first, and is a quiet button that opens **Go to**, tooltip "Go to… (G)") ‖ page field (`.input--sm`, 52px) "/ 612" · divider · zoom − / % menu / + · divider · **Keyboard shortcuts** (`CircleHelp`, tooltip "Keyboard shortcuts (?)", opens §5.7 — the toolbar's one help control, so it's there whether the sidebar is open or not) · focus mode (`Focus`, `aria-pressed`, tooltip "Focus mode (F)") · Appearance popover (`Palette`: theme `.segmented` Light/Sepia/Dark, plus "Invert page colours" switch, enabled only in dark; a remembered-but-unavailable switch stays neutral; then a **Reading** group of switches — *Reading ruler* (with an `R` kbd), *Book map*, *Chapter progress*; below a hairline, a **Library & storage…** row that opens §5.6) · **Review notes** (`.btn--sm`, `NotebookText`, count badge in accent). Pressed *panel* toggles (sidebar) use a quiet pressed fill, not the accent — accent is kept for bookmarks and "where you are". Below 1100px the section and the Review label collapse (count stays); below 960px the title does too. Nothing else goes in the toolbar as text: it must fit a 13" laptop (1280×720) with the sidebar open.
- **Chapter progress** (`.chapter-progress`, setting, on by default): a strip along the toolbar's bottom edge, one segment per top-level outline chapter (front matter gets its own; no outline, one segment), widths by page span, 2px gaps; 3px tall, 8px on hover or focus. Unread `--color-surface-sunken`; read part `--color-accent` (completed chapters dimmer); the current chapter has a 1px accent inset ring and `aria-current="location"`. Each segment is a button: hover/focus shows a float-chrome tooltip "Chapter 2: Newton's Laws · pp. 11–18 · 4 pages left" (others "40% read" / "not started"; printed page labels), click jumps (history). Pages and percentages only — never time estimates.
- **Go to** (`.go-to`, `G`): a modal `<dialog>` 12vh from the top, `min(640px, 100vw − 32px)`, raised surface, radius 14, `--shadow-lg`. A combobox ("Page, chapter, bookmark or note…") over a listbox of grouped rows — **Page** (anything the page field accepts, also `p 37` / `page 37`; selected first), **Contents**, **Bookmarks**, **Notes & highlights**, **Actions** (each with its `kbd`, labelled by the state it leads to: "Hide book map"), and finally "Search the book for “…”". Fuzzy matching with the matched letters in accent. Empty query: the chapters (current marked) and common actions. Footer: "G opens Go to from anywhere in the book" · "↑↓ move · Enter open · Esc close". Jumps go through history; focus returns where it was.
- `.sidebar`: 300px, bg surface, right border subtle. Header: `.segmented--full` tabs Contents · Bookmarks · Notes (+ a Search icon tab), margin 12px. Rows min-height 32px (wrap to ≤ 2 lines), indent 16px per level; current section `--color-accent-subtle` bg + `--color-accent` text; page number right-aligned xs muted tabular. Bookmark rows reveal rename/delete on hover or focus-within (always visible on touch). Footer: "Keyboard shortcuts" button + `?` kbd. Collapse: `translateX(-100%)` + width → 0 over `--duration-slow` (ease-out); collapsed content is `inert`.
- `.reader__viewport`: scroll container (bg `--color-bg-app`), thin scrollbar; 32px above the first page and 96px below the last, so the final lines can scroll clear of the Return pill. When keyboard-focused it shows a 2px `--color-focus-ring` line along the top edge (a full-viewport ring is too heavy). Each `.reader__page` is `.page-sheet` + `.page-margin` **flush**, centered as one unit (the page sits left of center by half the margin), `--page-gap` between pages. Sheet: `.page-sheet` (white, radius 2, `--shadow-sheet`, 1px hairline). Margin: `.page-margin` 280px, same height as sheet, bg `--color-margin-bg`, radius `0 6px 6px 0`; the sheet's shadow falls softly onto it. Never nest the margin inside `.page-sheet` (its `::selection` is transparent).
- *Planned, not yet built:* under 960px the margin collapses to a 44px rail of anchor dots; activating a dot opens the note in a popover. (Today the margin keeps its width and the viewport scrolls horizontally.)
- **Book map** (`.book-map`, setting, on by default): the whole book as a fore-edge along the reader's right edge, standing in for the viewport's vertical scrollbar (the horizontal one stays). 24px of paper at rest with faint page rules, hairline chapter dividers, notes as dots and highlights as short bars in their `--note-*-dot` colour, bookmarks as small ribbons, and an accent-outlined window for the visible pages. On hover or keyboard focus it opens to 52px (after a 60ms beat; it lingers 240ms) and thumb-index tabs appear — chapter numbers, the current one in accent. Hovering shows `.book-map-card` to the left: a lazily rendered page thumbnail (inverted with the pages), "p. 21 of 36", the section, and that page's annotations. **Snap:** annotations within 3px are one target; a target pulls the pointer from `min(6px, gap / 4)` beyond it, and pulls under 2px are dropped — so sparse marks are easy to land on, crowded stretches behave as if there were no snapping, and every page stays reachable. A snapped click lands exactly on the note, highlight or bookmark and pulses it; an ordinary click lands on the page. Drag scrubs without history and records one entry on release; `Esc` mid-drag goes back. Keyboard: `role="slider"`, ↑/↓ a page, PageUp/PageDown a chapter, Home/End, Enter jumps. In focus mode it recedes to 35% until reached for.
- **Focus mode** (`html.focus-mode`, `F` or the toolbar button; `Esc` also leaves): the toolbar slides up out of the way (it returns, over the page with `--shadow-md`, when the pointer reaches the top edge or anything in it takes keyboard focus), the sidebar closes (and reopens on leaving), pages other than the one at the centre dim to 45%, and margin notes recede to 30% (no shadow) until their page is hovered or a note is focused; anchor dots stay. Entering shows a float-chrome pill for 5s: "Focus mode · Move to the top edge for controls · F or Esc to leave". The reading position is kept exactly. Reduced motion: no sliding, opacity only.
- **Reading ruler** (`.reading-ruler`, `R` or the Appearance switch; works in or out of focus mode): a band about two lines tall (scales with zoom) that follows the pointer, with the page above and below it softly veiled. It takes no pointer events, so text stays selectable.

### 5.3 Margin notes
- **Geometry.** Column 280 = 16px gutter + **256px card** + 8px right padding. Anchor y = `anchor (0–1) × sheet height`.
- **`.margin-note`**: padding 10px 12px 12px; 1px `--note-border` + **3px left border `--note-dot`**; radius 6; `--shadow-sm`; serif 13.5/1.5 (`--font-weight-note`) in `--note-text`; bg `--note-bg`. Focusable (`tabindex="0"`, `role="group"`, `aria-label="Note on page 142"`).
- **`.margin-note__quote`**: italic serif 12.5/1.45, `--note-text`, 2px left rule `--note-border`, padding-left 8, margin-bottom 6, 3-line clamp. Optional, above the body.
- **`.margin-note__body`**: collapsed to 6 lines (≈ 121px); when clamped, `.margin-note__more` ("Show more", xs 600 underlined) expands it (200ms ease-out max-height). Expanded state resets on blur.
- **States.** Hover: `--shadow-md` + `.margin-note__actions` (swatch, delete `Trash2`) fade in 140ms as a small chrome pill straddling the card's top-right edge (20px above, 12px inside — clear of the first line of text; it overlaps the gap and a sliver of the note above, which is why it only shows for the hovered card) (always visible on focus-within/touch). Focus-visible: global 2px focus ring. **Editing** (`.is-editing`): 2px `--color-focus-ring` ring + `--shadow-md`, body becomes a borderless auto-growing editable field (`.note-field`, `role="textbox"`) with identical metrics (min 2 lines), a 5-swatch row (18px circles, `aria-label` = color name, selected has a check) and a delete button; text autosaves on input (debounced); `Esc`, `Ctrl/Cmd+Enter` or blur commits; an empty new note is discarded on blur. **Bold and italic:** `Ctrl/Cmd+B` and `Ctrl/Cmd+I` while writing, shown as you type (serif 600 / italic) in the margin, the review and their editors; paste and drops arrive as plain text; Enter is a line break. The note is still stored as plain text, with Markdown markers (`**bold**`, `*italic*`). Emphasis covers whole words: an asterisk *inside* a word is always literal, so older notes such as "2*3*4", "m*v*t" or "x**2" read exactly as before (formatting applied to part of a word is dropped when the note is saved; the text always survives). A typed `*` elsewhere is stored as `\*` only where it could be misread, and the Markdown export escapes in-word asterisks so other Markdown readers agree. One-line excerpts (sidebar, compact cards, Go to, the book map) show the text without markers, and the review filter matches that plain text. A focused card also responds to `Enter` (edit) and `Delete` (delete, with Undo). Jump target: 1.2s accent outline pulse.
- **Stacking.** Sort by anchor. For each card: `top = max(anchorY − 16, previousBottom + 8)` (8px gap; 16px = attach point below card top). Re-measure with `ResizeObserver`. If the stack would pass the page bottom, trailing cards fall back to a compact 32px one-line preview (click to expand in place). Cards being edited or expanded are never compacted — only cards after them are — and if the stack still does not fit it slides up to stay on the page. Never reorder; anchors are unchanged.
- **Anchor + leader.** `.margin-note__anchor`: 8px dot in `--note-dot`, centered on the sheet's right edge, 2px ring in `--page-sheet-bg`. `.margin-note__leader`: 1px line, `--note-dot` at 70%, from the dot to the card gutter at the attach y. When displaced, `.margin-note__tether` (1px vertical) joins anchor y to attach y. Each note's tether runs in its own 3-step lane (x = 7 / 10 / 13px, by order) so neighbouring tethers stay parallel and legible instead of overprinting at one x. Hover/focus: leader 2px, dot scales 1.25 (140ms).
- **Add-note ghost** `.margin-note-ghost`: appears over empty margin only, 256×32, 1px dashed `--color-border-control`, radius 6, `Plus` 16 + "Add note" (sm 500, secondary), centered on the pointer y snapped to 4px, plus a faint dot on the page edge; fade 120ms, follows y without easing. Click → note in last-used color (default amber), editor focused. `N` does the same at mid-viewport.
- **Selection:** `.selection-popover` — float chrome (`--color-float-*`), 32px high, radius 8, `--shadow-lg`, 8px above the end of a single-line selection (below the last line of a multi-line one, so it never covers selected text; it flips when there is no room), kept inside the page area (clear of the toolbar and sidebar). Left to right: a `Highlighter` icon and five colour swatches (`aria-label` "Highlight Amber"…, tooltip "Highlight amber"; the ringed one is the colour `H` will use) · a `H` kbd · divider · "Add margin note" + `N` hint. A swatch highlights the selection; "Add margin note" creates a note anchored at the middle of the first selected line with `__quote` pre-filled. It hides on scroll, `Esc`, a collapsed selection, or while a note is being edited.
- **Highlights.** Coloured text emphasis, one bar per line of the selection, stored as fractions of the page box so they follow every zoom. `H` with a selection highlights it in the colour used last (the most recent highlight's colour after a reload).
  - **`.page-highlight`** (page overlay, beneath the text layer so a selection always draws over it): radius 2, `mix-blend-mode: multiply` so ink stays dark and the paper takes the colour. Fill = `--note-border` (light, sepia); dark's dimmed paper mixes `--note-dot` into `--page-sheet-bg`; night pages (`.invert-pages`) use `screen` with a translucent `--note-dot`. Bars take no pointer events, so text under them can be selected as usual; clicks are hit-tested against the stored rectangles instead.
  - **States.** Hover (or hovering its linked note) deepens the fill and adds a 1.5px `--note-dot` ring; a jump from the sidebar or review flashes a 1.2s accent ring (static under reduced motion).
  - **Highlight popover** (a plain click, with no drag and no selection, on a highlight): `.selection-popover.highlight-popover` above the highlight's lines — five swatches (colour change), **Add note** (or **Open note** if one exists), `Trash2` delete. Deleting offers Undo; the note stays, unlinked.
  - **Linked note.** "Add note" makes a note anchored at the highlight's first line, quoting its text, in its colour (`MarginNote.highlightId`). Its `.margin-note__quote.is-linked` takes a 3px rule in the *highlight's* colour (`[data-highlight-color]` → `--link-color`), the card carries "on a … highlight" in its `aria-label`, and hovering the card emphasises the highlight.
  - **Sidebar Notes tab** lists notes and highlights together by page, top to bottom: a note shows its colour dot and a two-line excerpt; a highlight without a note shows a 4×16 marker bar in its colour and its passage in italic. Header: "3 notes · 2 highlights" + **Review all**. Clicking an item jumps (recorded in history) and flashes it.
- **Bookmark ribbon** (`.bookmark-ribbon`, a `<button>` holding `.page-sheet__ribbon`): 22×38px, top 0, right 24px, `--color-bookmark`, `clip-path: polygon(0 0,100% 0,100% 100%,50% 78%,0 100%)`; enters `translateY(-100%)→0`, 320ms spring. It is where you bookmark a page: with the pointer within 96px of a page's top and 144px of its right edge, a faint ghost ribbon appears (never while a button is held, text is selected, or just after scrolling); hovering it takes the bookmark colour, and a click sets or clears the bookmark (tooltip "Bookmark this page (B)" / "Remove bookmark (B)"). Only the ribbon's own box takes pointer events, so text and links under the corner behave as before. `aria-label` "Bookmark page 14" with `aria-pressed`; kept out of the Tab order (keyboard: `B`, Go to, and "Bookmark this page" in the sidebar's Bookmarks tab). Touch shows the ghost always.

### 5.4 Return pill
`.return-pill` is absolutely positioned inside `.reader__viewport`: **bottom 24px, horizontally centered on the viewport** (not the window). Height 40, padding `0 6px 0 14px`, radius full, bg `--color-float-bg`, text `--color-float-text` sm/500, 1px `--color-float-border`, `--shadow-lg`. Content: `Undo2` 16 · "Return to p. **142**" (number in `--color-float-accent`, tabular) · `.return-pill__close` (28px circle, `X` 16, `aria-label="Dismiss"`). Tooltip on the main button: "Alt+←".
- Enter: 320ms spring from `opacity 0; translateY(16px) scale(.96)` plus one 900ms soft accent ring pulse (`box-shadow 0 0 0 0 → 0 0 0 10px` fading to transparent). Exit: 140ms ease-in, fade + 8px down. Hover: bg lightens 6%.
- Dismiss: ×, `Esc`, activating it, or after 12s without hover/focus. One pill at a time; a new jump cross-fades the label (120ms). `role="status"` live region; the action is a real `<button>`.
- **Toasts** (`.toast`, same float chrome, pill-shaped, 40px) stack **bottom-left** (24px inset) so they never meet the Return pill, which is centred over the document. In the reader they rise 56px higher so they clear the sidebar footer instead of covering it (`body:has(.sidebar)`). Optional accent action ("Undo"), × dismiss; error toasts add a danger dot. Enter 320ms spring.

### 5.5 Collated notes review
- Replaces the reader body; one 48px toolbar. Left → right: `ArrowLeft` "Back to book" · divider · **stacked heading** — title "Notes · {Book}" (serif 18, truncates; 16 below 1360px) over a count line (xs muted, tabular: "13 notes on 6 pages", or "2 of 13 notes on 2 pages" while filtering; `role="status"`) — · spacer · **text filter** (`.review-search`, `.input--sm` 176px, `Search` icon, `/` kbd hint that becomes a clear × once there is text) · **colour filter chips** (`.review-chip`, 26px, 12px dot; active = note tint + 1.5px dot ring; the others dim to 60%; tooltip "Amber · 4") · **Comfortable | Dense** (`.segmented`) · quiet theme switcher (icons only, no tray, after a hairline — it is rarely used here) · **Export Markdown** (`.btn`, `Download`; icon-only below 1120px; tooltip says it exports all notes, ignoring filters; toast "Exported 13 notes"). Filters and export are hidden when the book has no notes. Content column max-width 880, centered, padding 32px 24px.
- **Filtering.** The text filter matches note text, quotes and highlighted passages (case-insensitive; every word must match; a note matches through the highlight it was written for); matches are highlighted with `.review-mark` (accent at 18%, 2px radius). The colour chips match any colour an item carries (a note and its highlight can differ) and count notes and highlights together. Empty result: "No notes match your filters" with a **Clear filters** button.
- **Highlights in the review.** Pages with only highlights are listed too. A highlight without a note is a `.review-highlight` row — a 4px bar in its colour, its passage in serif (4-line clamp), and *Show in book* / *Delete highlight* (Undo toast) revealed on hover or focus — interleaved with notes by vertical position. A highlight with a note appears once, as its note, whose quote (`.review-note__quote.is-highlight`) shows the passage with a 3px rule in the highlight's colour. Thumbnails draw each highlight as a small multiplied bar. The count line reads "3 notes and 2 highlights on 4 pages" (or "5 of 12 notes and highlights on 2 pages" while filtering).
- **Markdown export** puts a highlight under its page as `> passage` followed by `_(highlight, amber)_`; the note written for it follows underneath (the passage is quoted once). The export is ordered top to bottom with notes, and its summary line counts both.
- **Keyboard** (when not typing): `j` / `k` move focus to the next / previous note (scrolling it into view), `/` focuses the filter (`Esc` clears it, then blurs), `Enter` or click edits the focused note, `Esc` ends editing, then `Esc` or `Shift+R` returns to the book. A focused note shows the standard focus ring and its jump button.
- `.review-row` (comfortable): grid `160px 1fr`, gap 24, padding 20px 0, 1px `--color-border-subtle` divider. `.review-row__header` "**Page 37** · Chapter 3: Kinematics" (600 base + sm secondary, truncating), "Go to page" `.btn--ghost.btn--sm` (`ArrowUpRight`) revealed on hover/focus.
- Thumbnail `.page-thumb`, 160px wide; `.review-row__dot` 10px at the thumbnail's right edge (50% outside, 2px ring) at `anchor × height`. Each `.review-note` repeats its dot (8px) at the start of the line, ordered by anchor: serif 15/1.55, optional quote (italic 13 secondary, 2px rule), padding 8px 0, hover bg `--color-hover`; click edits inline; a jump button per note.
- **Dense** (`.review--dense`): no thumbnails, single column, row padding 12px 0, header inline, notes serif 13.5/1.5 padding 4px 0 — roughly 2× notes per screen. Switch 200ms (thumbnails fade, rows collapse); preference persists.

### 5.6 Library & storage
Where books and notes live, and how to keep them safe. A native modal `<dialog class="storage-dialog">` (`aria-labelledby` its heading, so its name is "Library & storage"), mounted once in the app shell and opened from the library's top line or from the reader's Appearance popover (a quiet **Library & storage…** row under a hairline, `HardDrive`). Width `min(580px, 100vw − 32px)`, max-height `100dvh − 32px`, radius 14, `--shadow-lg`, scrim backdrop. Focus lands on the close button; `Esc` or × closes it and focus returns to the control that opened it (for the Appearance row, the Appearance button). The header (icon tile in `--color-accent-subtle`, title 18/600, one-line subtitle, ghost × button) stays put while the body scrolls.

Four sections separated by hairlines, each `<section aria-labelledby>` with a 16/600 UI-font title, an 18px muted icon and an optional intro (13px secondary, ≤ 62ch):
- **Library folder** (`FolderSync`). Intro: "Keep your PDFs in a folder — on this computer, OneDrive, Dropbox or Google Drive — and Scriptorium reads them there and saves your notes beside them, so every device that opens the folder stays in step." Below it a **status card** (`.storage-card`: `--color-surface`, 1px subtle border, radius 10, 36px icon tile, 15/600 title, 13px secondary detail, actions) for each `useSyncStore` status:

  | Status | Card | Actions |
  | --- | --- | --- |
  | `unsupported` | "Folder sync needs Chrome or Edge on a computer." · "Use backups below to move your notes." | — |
  | `unlinked` | "No folder linked" · "Using Google Drive? Install Google Drive for desktop, then choose a folder inside it." | **Link a folder…** (primary) |
  | `needs-permission` | accent-tinted (`.storage-card--notice`): "Scriptorium needs your permission to open “Textbooks” again." | **Reconnect** (primary), Unlink |
  | `syncing` | spinner, `progress.label`, "3 of 12" and a 4px accent `role="progressbar"` | — |
  | `idle` | "Synced with “Textbooks”" · "Last synced 2 minutes ago" | Sync now, Change folder…, Unlink (ghost) |
  | `error` | danger-tinted (`.storage-card--error`): the error text | **Try again** (re-syncs; re-links when no folder), Change folder…, Unlink |

  Other devices appear under "ALSO USED BY" (xs tracked caps) as "Chrome on macOS · yesterday". **Unlink** opens a `.library-dialog` confirmation — "Unlink “Textbooks”? Books from this folder leave your library on this device. Your notes stay in the folder and come back when you link it again." — focus starts on Cancel; afterwards focus moves to the card's primary action. The card title is a polite live region (progress counts live outside it, so ticks don't chatter). A failed action shows its message inline (`role="alert"`, danger text); dismissing the folder picker isn't a failure.
- **This device** (`Laptop`): a labelled `.input` (max 340px, 40 characters) for the device name, hint "Other devices use this name to say where you left off.", committed on blur or Enter, with a polite "Saved.". An empty name falls back to the default ("Chrome on Windows").
- **Backups** (`ArchiveRestore`): "Backups include notes, highlights, bookmarks and reading progress — not the PDFs. Restoring merges; it never deletes newer notes." **Export backup** (`Download`) saves `Scriptorium backup 2026-10-27.json` and toasts "Backup saved — 12 books, 340 notes" (annotation kinds with nothing in them are left out; an empty library saves nothing and says so). Under the buttons a polite status line says where it went ("Saved as “Scriptorium backup 2026-10-27.json”."). **Restore from backup…** (`Upload`, a hidden `.json` file input) answers "Restored notes for 12 books." — or "Nothing new in that backup — your library already has it all." — and, for books whose PDF isn't in the library yet, "Add these PDFs to see their notes:" with up to five titles and "and N more". A file that isn't a backup reads "That file isn’t a Scriptorium backup." (danger text, `CircleAlert`).
- **Storage** (`HardDrive`): a card — `ShieldCheck` "Protected from automatic clean-up", or `ShieldAlert` "The browser may clear this data when space runs low" with **Protect my library** (asks the browser; if it declines: "Your browser didn’t allow it this time. A linked folder or backup still keeps your notes safe."), or "Stored in this browser" when the browser doesn't say — with "Using 412 MB" beneath. Note: "Clearing this site’s data in your browser removes books you imported here. Books in a linked folder — and their notes — are safe in the folder."

Persistent storage is requested silently, never from a prompt of its own: after a successful import, after a folder is linked, and once at launch when the library already has books — except in Firefox, which would prompt unprompted at launch, so there it only follows an import or a link.

Toasts are not in the top layer, so results that matter while the dialog is open are also written into the dialog.

### 5.7 Keyboard shortcuts & help
- **One list.** Every shortcut is data in `src/features/commands/commands.ts` (label, group, where it works, keys). Key handlers match against it, and the dialog, tooltips (`withShortcut` → "Zoom in (+)"), `aria-keyshortcuts` and Go to's hints are generated from it, so a key is written down once — and making shortcuts configurable later only means overriding keys there. Labels follow the platform ("Ctrl+F" / "⌘F", "Alt+←" / "⌥←").
- **Always one click away.** `?` opens the dialog on every screen (library, reader, review). The **Keyboard shortcuts** button (`CircleHelp`) sits in the library's top line, the reader toolbar and the review toolbar; the reader's sidebar footer keeps its labelled button.
- **The dialog** (`.shortcuts-dialog`, "Keyboard shortcuts", "Every key in Scriptorium, and where to click instead."): `min(760px, 100vw − 32px)`, the groups (Navigate · Search · Read · Annotate · Writing a note · Notes review) in two columns, keys as keycaps with alternatives joined by "or", then **Without the keyboard** — how to reach each feature by pointer (click the margin to add a note, select text to highlight, hover the page corner to bookmark, hover a link to preview, the book map, the section name for Go to, Appearance → Reading, Review notes). Scrolls when the window is short; focus returns where it was.
- Shortcuts are few and single keys where possible; every one is listed here and shown wherever its action lives. No hidden keys.

## 7. Accessibility

- Text ≥ 4.5:1, UI boundaries/focus ≥ 3:1 in all themes (see §3). Re-check if any token changes.
- `:focus-visible` shows a 2px ink-blue ring, 2px offset, on every interactive element; never remove it. Pointer clicks show none.
- Everything is keyboard reachable: toolbar → sidebar → pages → margin notes (tab order follows page order). Outline is `role="tree"` (arrow keys); sidebar tabs follow the tabs pattern; segmented items are `role="radio"` or `tab` with `aria-checked`/`aria-selected`. Note colors are named in `aria-label`s — color is never the only signal.
- Targets ≥ 28px (toolbar controls 34px). `data-tooltip` supplements, never replaces, `aria-label`; a tooltip is hidden while its trigger's menu is open (`aria-expanded="true"`) so it never sits on top of the popover.
- Return pill and exports announce via live regions. Honors `prefers-reduced-motion`. Focus uses `outline`, so it persists in forced-colors mode.
